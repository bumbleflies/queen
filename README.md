# queen

Finance & operations app for bumbleflies: clients, invoices (PDF + Drive filing), credit notes and automatic payment reconciliation against the GLS bank feed in Firefly III. Replaces the "Debitoren und Ausgangsrechnungen" Google Sheet and is intended to become the invoicing backend for [leagues.finance](https://github.com/bumbleflies/leagues.finance).

Status: planning — see [`docs/plans/2026-10-06-queen.md`](docs/plans/2026-10-06-queen.md) and the UI mocks in [`docs/mocks/`](docs/mocks/).
