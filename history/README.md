# history/

Feature logs for queen, one file per shipped feature: `YYYY-MM-DD_feature-name.md`.

Each log records:

- **Problem**: why the feature was needed
- **Solution**: what was built
- **Files changed**: the main ones
- **Deployment results**: where it runs and what was verified
- **Verification commands**
- **Success criteria**
- **Known issues** and **future enhancements**

The repo is public. Logs must not contain customer data or company figures: no real amounts, balances or tax results.

The plans in `docs/plans/` say what was intended. These logs say what actually shipped.
